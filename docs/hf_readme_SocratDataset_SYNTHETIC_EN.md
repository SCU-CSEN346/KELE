# SocratDataset-SYNTHETIC-EN

**75 freshly generated English Socratic teaching dialogues — clean-probe evaluation set for contamination-controlled benchmarking.**

SocratDataset-SYNTHETIC-EN is a small, fully synthetic corpus of Socratic science tutoring dialogues in English, generated by Claude Sonnet 4.6. It was created specifically as a **contamination-control evaluation set**: because these dialogues were not derived from any training corpus, any model's performance here reflects genuine Socratic teaching generalization, not memorization.

This dataset is the English companion to [ulises-c/SocratDataset-SYNTHETIC](https://huggingface.co/datasets/ulises-c/SocratDataset-SYNTHETIC) (Chinese). It is produced as part of the KELE reproduction and extension study (CSEN 346, Santa Clara University, 2026).

> **Chinese companion available:** See [ulises-c/SocratDataset-SYNTHETIC](https://huggingface.co/datasets/ulises-c/SocratDataset-SYNTHETIC) for the 75-record Chinese synthetic dataset used in the contamination benchmarks.

---

## Motivation

SocratTeachLLM (Peng et al., EMNLP 2025) is a Chinese-trained Socratic teaching model. Evaluating its cross-lingual transfer requires test data that was never seen in training — in either language. SocratDataset-SYNTHETIC-EN provides an English evaluation surface that is:

1. **Unseen**: no record was derived from SocratDataset or any prior training corpus
2. **English**: tests genuine cross-lingual transfer (SocratTeachLLM is Chinese-trained)
3. **Independently generated**: not a translation of the Chinese SYNTHETIC — topics and dialogues were generated directly in English

## Dataset Structure

Each record contains:

| Field | Type | Description |
|---|---|---|
| `id` | int | Record identifier (200001–200075) |
| `question` | string | English science question posed by the student |
| `answer` | string | Correct answer |
| `dialogue` | list | Sequence of turns, each with `student`, `teacher`, and `state` fields |

Each `dialogue` turn:

| Field | Type | Description |
|---|---|---|
| `student` | string | Student utterance in English |
| `teacher` | string | Teacher (ground-truth) Socratic response in English |
| `state` | string | Pedagogical state code (e.g. `c8`, `d30`) following the SocRule 35-state schema |

### SocRule Stages

| Stage | Code range | Description |
|---|---|---|
| a — Initiation | a1 | Dialogue starts; student poses the question |
| b — Concept Probing | b2–b7 | Teacher probes prior knowledge |
| c — Inductive Reasoning | c8–c29 | Core teaching stage; can repeat multiple turns |
| d — Answer Derivation | d30–d33 | Guide student to the correct answer |
| e — Summary | e34 | Dialogue ends; teacher summarises |

## Generation Details

Dialogues were generated by Claude Sonnet 4.6 using the SocRule framework specification as the generation prompt, adapted to English. Each dialogue:
- Follows the strict five-stage monotonic progression (a → b → c → d → e)
- Uses question topics drawn from elementary school science (physics, chemistry, biology, earth science, astronomy)
- Was generated independently from the Chinese SYNTHETIC dataset — not a translation
- Has all five stages represented and annotated with valid SocRule state codes

The generation approach mirrors [scripts/generate_synthetic_socrat.py](https://github.com/ulises-c/csen-346/blob/main/scripts/generate_synthetic_socrat.py) with the prompt adapted for English-language output. IDs start at 200001 to avoid collision with SocratDataset (1–6803) and the Chinese SYNTHETIC (100001–100075).
