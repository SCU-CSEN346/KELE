# Attribution — SocratDataset-SYNTHETIC

## Original Work

This dataset was generated to support the evaluation methodology introduced in the KELE paper:

> Peng, Yuan et al. "KELE: A Multi-Agent Framework for Structured Socratic Teaching with Large Language Models."
> *Findings of the Association for Computational Linguistics: EMNLP 2025.*
> https://aclanthology.org/2025.findings-emnlp.888/

The SocRule framework (5 stages, 34 strategies) that structures all dialogues in this dataset is the intellectual property of the KELE research team. All generation prompts in this dataset are derived from the SocRule state-transition specification described in the KELE paper.

## Source Data

Unlike SocratDataset, this dataset is **fully synthetic** — it does not derive from any external question bank. All questions, answers, and dialogue turns were generated by Claude Sonnet 4.6 using the SocRule framework as the generation schema.

Topics are drawn from Chinese elementary school science (grades 3–6), chosen to be distinct from the topics present in SocratDataset to prevent evaluation contamination.

## Generation

**Generator model:** Claude Sonnet 4.6
**Generation script:** https://github.com/ulises-c/csen-346/blob/main/scripts/generate_synthetic_socrat.py
**Authors:** Ulises Chavarria, Maximilian Khan
**Context:** CSEN 346 (Natural Language Processing), Santa Clara University, 2026

The dataset was generated in two batches:
- `default` (37 records, IDs 100001–100037): original contamination-probe batch
- `n75_extension` (38 records, IDs 100038–100075): second batch extending the evaluation pool

## Purpose

SocratDataset-SYNTHETIC was created specifically as a **contamination-control evaluation set**. SocratTeachLLM was fine-tuned on SocratDataset, so evaluating it on SocratDataset conflates memorization with generalization. These synthetic dialogues were never part of any training corpus, providing a truly unseen evaluation surface.

The contamination evidence motivating this dataset is documented in:
https://github.com/ulises-c/csen-346/blob/main/docs/SOCRATTEACHLLM_CONTAMINATION_PROOF.md
