# SocratDataset-SYNTHETIC

**75 freshly generated Chinese Socratic teaching dialogues — clean-probe evaluation set for contamination-controlled benchmarking.**

SocratDataset-SYNTHETIC is a small, fully synthetic corpus of Socratic science tutoring dialogues generated by Claude Sonnet 4.6. It was created specifically as a **contamination-control evaluation set**: because these dialogues were not derived from SocratDataset (the training corpus for SocratTeachLLM), any model's performance here reflects genuine Socratic teaching generalization, not memorization of training data.

This dataset is a companion to [ulises-c/SocratDataset](https://huggingface.co/datasets/ulises-c/SocratDataset) and [ulises-c/SocratDataset-EN](https://huggingface.co/datasets/ulises-c/SocratDataset-EN), produced as part of the KELE reproduction and extension study (CSEN 346, Santa Clara University, 2026).

> **English companion available:** See [ulises-c/SocratDataset-SYNTHETIC-EN](https://huggingface.co/datasets/ulises-c/SocratDataset-SYNTHETIC-EN) for independently generated English synthetic dialogues.

## Dataset Summary

| Property | Value |
|---|---|
| Language | Chinese (Simplified) |
| Records | 75 total (37 in `default` split, 38 in `n75_extension` split) |
| Dialogue turns | 5–6 per record |
| Stage coverage | a, b, c, d, e (all five SocRule stages) |
| Generation model | Claude Sonnet 4.6 |
| Framework | SocRule (KELE, Peng et al. 2025) |

The dataset is organized into two configs:

| Config | Records | IDs | Notes |
|---|---|---|---|
| `default` | 37 | 100001–100037 | Original generation batch; used in contamination benchmarks |
| `n75_extension` | 38 | 100038–100075 | Second generation batch; extends the evaluation pool |

## Motivation

SocratTeachLLM (Peng et al., EMNLP 2025) is fine-tuned on SocratDataset's training split and evaluated on the same dataset's test split. Our study found evidence of benchmark contamination: SocratTeachLLM produces character-for-character identical outputs to held-out test ground truth at a 1.4% rate, and train/test ROUGE distributions are statistically indistinguishable (Δ ROUGE-1 = +0.22). Standard SocratDataset evaluation therefore cannot cleanly separate learned teaching ability from memorization.

SocratDataset-SYNTHETIC provides a **truly unseen** evaluation surface. When SocratTeachLLM is evaluated here, its ROUGE-1 drops from ~44 (on SocratDataset) to 35.72, and state accuracy drops to 29.38% — confirming that a substantial portion of its measured performance on SocratDataset is memorization-driven rather than genuine generalization.

## Dataset Structure

Each record contains:

| Field | Type | Description |
|---|---|---|
| `id` | int | Record identifier (100001–100075) |
| `question` | string | Chinese science question posed by the student |
| `answer` | string | Correct answer |
| `dialogue` | list | Sequence of turns, each with `student`, `teacher`, and `state` fields |

Each `dialogue` turn:

| Field | Type | Description |
|---|---|---|
| `student` | string | Student utterance in Chinese |
| `teacher` | string | Teacher (ground-truth) Socratic response in Chinese |
| `state` | string | Pedagogical state code (e.g. `c8`, `d30`) following the SocRule 35-state schema |

### SocRule Stages

| Stage | Code range | Description |
|---|---|---|
| a — Initiation | a1 | Dialogue starts; student poses the question |
| b — Concept Probing | b2–b7 | Teacher probes prior knowledge |
| c — Inductive Reasoning | c8–c29 | Core teaching stage; can repeat multiple turns |
| d — Answer Derivation | d30–d33 | Guide student to the correct answer |
| e — Summary | e34 | Dialogue ends; teacher summarises |

### Stage distribution (`default` split — 215 turns total)

| Stage | Phase | Turns |
|---|---|---|
| a | Student Questioning | 37 |
| b | Concept Probing | 50 |
| c | Inductive Reasoning | 62 |
| d | Rule Construction | 29 |
| e | Teacher Summary | 37 |

```python
from datasets import load_dataset

# Original 37-record evaluation set (used in contamination benchmarks)
ds = load_dataset("ulises-c/SocratDataset-SYNTHETIC", split="train")

# Extended 38-record batch
ds_ext = load_dataset("ulises-c/SocratDataset-SYNTHETIC", name="n75_extension", split="train")

print(record["question"])
for turn in record["dialogue"]:
    print(f"[{turn['state']}] Student: {turn['student'][:60]}")
    print(f"       Teacher: {turn['teacher'][:60]}")
```

## Benchmark Results

SocratTeachLLM evaluated on the `default` split (BERT consultant + fewshot10, n=37):

| Metric | SocratDataset (test) | **SocratDataset-SYNTHETIC** | Delta |
|---|---|---|---|
| ROUGE-1 | ~44.61 | **35.72** | −8.89 |
| ROUGE-2 | ~26.04 | **14.90** | −11.14 |
| ROUGE-L | ~38.02 | **27.53** | −10.49 |
| BLEU-4 | ~19.60 | **10.59** | −9.01 |
| State acc (overall) | ~38.44% | **29.38%** | −9.06 pp |

The ~9–11 point surface-form drop and ~9 pp state accuracy drop on truly unseen data quantifies the memorization contribution to SocratTeachLLM's published benchmark numbers.

## Generation Details

Dialogues were generated by Claude Sonnet 4.6 using the SocRule framework specification as the generation prompt. The generation script is open-source:
**[github.com/ulises-c/csen-346](https://github.com/ulises-c/csen-346/blob/main/scripts/generate_synthetic_socrat.py)**

Each dialogue:
- Follows the strict five-stage monotonic progression (a → b → c → d → e)
- Uses question topics drawn from Chinese elementary school science (distinct from SocratDataset's topics)
- Has all five stages represented and annotated with valid SocRule state codes
- Was generated in batches of 5 dialogues per API call (16K output token budget)
