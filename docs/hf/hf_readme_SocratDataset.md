# SocratDataset

**Chinese elementary-school science tutoring dialogues following the SocRule framework.**

This is the original Chinese dataset used to train SocratTeachLLM, as published in the KELE paper (EMNLP 2025 Findings). It contains 6,803 multi-turn Socratic dialogues covering elementary science topics for grades 1–6.

> **English translation available:** See [ulises-c/SocratDataset-EN](https://huggingface.co/datasets/ulises-c/SocratDataset-EN) for a fully translated English version of this dataset.

---

## Dataset Summary

| Property | Value |
|---|---|
| Language | Chinese (Simplified) |
| Domain | Elementary school science (grades 1–6) |
| Records | 6,803 |
| Dialogue turns | 5–12 per record (median: 6) |
| Question types | Multiple choice (`multiple_choice`), True/False (`true_false`) |
| Framework | SocRule (5 stages, 34 strategies) |

The source questions come from the **CSQ dataset** (Chinese elementary science questions), filtered and augmented using the KELE B.3 pipeline, then converted into multi-turn Socratic dialogues using the KELE B.4 pipeline.

---

## Dataset Structure

Each record contains the following fields:

| Field | Type | Description |
|---|---|---|
| `id` | int | Unique record identifier (1–6803) |
| `grade` | string | Grade level and volume (e.g., `4小学四年级上册`) |
| `chapter` | string | Chapter or topic label |
| `mission` | string | Question type: `选择题` (multiple choice) or `判断题` (true/false) |
| `question` | string | The original question text |
| `options` | list[string] | Answer options |
| `answer` | string | Correct answer |
| `newHint` | string | Guiding clue generated by B.3 (does not reveal the answer) |
| `newKnowledgePoint` | string | Academic concept description generated by B.3 |
| `newAnalyze` | string | Full analysis of the question and each option generated by B.3 |
| `dialogueRound` | int | Number of dialogue turns |
| `dialogue` | list[dict] | The multi-turn Socratic dialogue (see below) |

Each turn in `dialogue` contains:

| Field | Type | Description |
|---|---|---|
| `student` | string | Student utterance (turn 0 includes the question and options) |
| `evaluation` | string | Consultant's assessment of the current stage and state |
| `state` | string | SocRule state code (`a1`, `b2`–`b7`, `c8`–`c29`, `d30`–`d33`, `e34`) |
| `action` | string | Teaching strategy the teacher should apply |
| `teacher` | string | Teacher's Socratic response |

### SocRule Stages

| Stage | Code range | Description |
|---|---|---|
| a — Initiation | a1 | Dialogue starts; student poses the question |
| b — Concept Probing | b2–b7 | Teacher probes prior knowledge |
| c — Inductive Reasoning | c8–c29 | Core teaching stage; can repeat multiple turns |
| d — Answer Derivation | d30–d33 | Guide student to the correct answer |
| e — Summary | e34 | Dialogue ends; teacher summarises |

## Usage

```python
from datasets import load_dataset

ds = load_dataset("ulises-c/SocratDataset", split="train")
record = ds[0]

print(record["question"])
for turn in record["dialogue"]:
    print(f"[{turn['state']}] Student: {turn['student'][:60]}")
    print(f"       Teacher: {turn['teacher'][:60]}")
```

### Training Objective

The paper formulates teacher fine-tuning as:

```
P(teacher_response | dialogue_history, evaluation, action)
```

The `evaluation` and `action` fields are required conditioning signals — do not discard them. At inference time a consultant agent produces these fields before the teacher agent generates its response.

## Provenance

This dataset was produced by the KELE research team using the pipeline described in Appendix B.3 and B.4 of the paper. The raw source questions come from the CSQ dataset (Liu et al., 2025).

The JSON file (`SocratDataset.json`) was originally distributed via the KELE GitHub repository and was not published directly on HuggingFace. This HuggingFace upload was created by [Ulises Chavarria](https://huggingface.co/ulises-c) to make the dataset more accessible.
