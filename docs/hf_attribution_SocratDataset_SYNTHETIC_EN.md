# Attribution — SocratDataset-SYNTHETIC-EN

## Original Work

This dataset was generated to support cross-lingual evaluation using the KELE SocRule framework:

> Peng, Yuan et al. "KELE: A Multi-Agent Framework for Structured Socratic Teaching with Large Language Models."
> *Findings of the Association for Computational Linguistics: EMNLP 2025.*
> https://aclanthology.org/2025.findings-emnlp.888/

The SocRule framework (5 stages, 34 strategies) that structures all dialogues in this dataset is the intellectual property of the KELE research team. All generation prompts in this dataset are derived from the SocRule state-transition specification described in the KELE paper.

## Source Data

This dataset is **fully synthetic** — it does not derive from any external question bank or prior dataset. All questions, answers, and dialogue turns were generated by Claude Sonnet 4.6 using the SocRule framework as the generation schema, with prompts written in English.

This dataset was generated **independently** from the Chinese SYNTHETIC companion ([ulises-c/SocratDataset-SYNTHETIC](https://huggingface.co/datasets/ulises-c/SocratDataset-SYNTHETIC)) — it is not a translation. Topics and dialogues were generated directly in English covering elementary school science (physics, chemistry, biology, earth science, astronomy).

## Generation

**Generator model:** Claude Sonnet 4.6
**Generation approach:** Adapted from [scripts/generate_synthetic_socrat.py](https://github.com/ulises-c/csen-346/blob/main/scripts/generate_synthetic_socrat.py) with an English-language prompt
**Authors:** Ulises Chavarria, Maximilian Khan
**Context:** CSEN 346 (Natural Language Processing), Santa Clara University, 2026

IDs start at 200001 to avoid collision with SocratDataset (1–6803) and the Chinese SYNTHETIC (100001–100075).

## Purpose

SocratDataset-SYNTHETIC-EN was created to provide an English-language contamination-free evaluation surface. It supports:

1. **Cross-lingual transfer evaluation**: Testing whether Chinese-trained Socratic models (e.g. SocratTeachLLM) generalize to English
2. **English-language fine-tuning evaluation**: Assessing English-language Socratic teaching models on unseen data
3. **Complementing the Chinese SYNTHETIC**: Together the two SYNTHETIC datasets enable bilingual contamination-controlled benchmarking
